# QDTech v1.8.8 益智游戏馆与体感迷宫交接

发布日期：2026-07-30
发布基线：GitHub `v1.8.7`

## 范围

- 新增默认关闭的 `CONFIG_QDTECH_EXPERIMENT_PUZZLE_ARCADE`；发布默认配置通过 `sdkconfig.puzzle_arcade.defaults` 启用，关闭时可独立构建，不影响稳定基线。
- 游戏馆包含数独花园、密码侦探、萌宠推箱、甜点消消乐、体感迷宫五项内容。
- 游戏数据、封面与 48 个体感迷宫关卡均位于 SD 卡 `games/puzzle_arcade/`；固件不把关卡或图片常驻到内部 SRAM。

## 体感迷宫

- 复用原有 BMI270 PSRAM 栈任务；仅在迷宫页面将采样提升到 40 ms，退出页面立即回到原有低频沙漏轮询，不新增 FreeRTOS 任务、定时器、网络服务、NVS 或分区。
- 进入关卡后先采集 12 个稳定样本校准；倾斜阈值为 110，连续移动间隔为 220 ms。
- 已根据实机反馈反转水平与垂直方向。最终方向修正版通过完整低速刷写和启动验证；发布后仍建议按“重新校准 → 平放约两秒 → 四向倾斜”做一次用户侧确认。

## 界面与兼容性

- 游戏页采用固定深色文字和独立顶栏，避免经典主题的浅色文本在浅色棋盘上不可见；修复自绘数字的短生命周期文本导致的空白问题。
- 游戏馆入口升级为彩色卡片目录，选中态保持深色标题，不再出现白色高亮吞没文字。
- 保持天气、Wi-Fi、时间同步、MQTT、音频、电台、SD 卡、掌卦、沙漏及 BMI270 原有路径不变。

## 构建与实机验证

- ESP-IDF 5.5：游戏馆开启/关闭两套配置均构建通过。
- 开启版 App：`0x679980` / 6,789,504 字节；7 MB App 槽剩余 `0x86680`（8%）。
- COM3 实机完成完整 115200 USB 复位刷写，所有分区数据哈希验证通过；启动镜像 ELF SHA-256 前缀：`066fb7254`。
- 启动确认：8 MB PSRAM、LCD/LVGL、触摸、BMI270、SD 电台（47 台）、Wi-Fi、MQTT、SNTP、天气 HTTP 200 均正常；内部 SRAM 稳态约 11–12.6 KB，观测最小值约 9.7 KB，未见 panic、watchdog 或低内存告警。

## 发布与回滚

- OTA 使用 `*-app.bin`，不要将完整合并镜像作为常规 OTA 包。
- 完整镜像仅用于恢复性全量刷写；普通回滚使用 `v1.8.7` 的 App-only 镜像，以保留 NVS 与 SD 数据。
