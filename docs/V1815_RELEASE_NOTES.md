# QDTech v1.8.15 幸运左轮正式版

发布日期：2026-08-02

源码发布提交：`f61c1df`（`release: v1.8.15 version correction`）。

## 版本说明

- v1.8.15 是幸运左轮功能和自定义中弹音效完成验收后的正式公开版本。
- v1.8.14 曾短暂作为候选构建发布，现已明确标记为由 v1.8.15 取代。
- 与已验收候选构建相比，本次仅修正固件版本、SD 卡资源版本和发布资料，不改动已验证的游戏、网络、天气、语音、电台、日历等功能。

## 主要变化

- 益智游戏馆新增“幸运左轮”：可选择 1–5 颗玩具弹，摇动开发板旋转六孔转轮，停稳后点击扳机揭晓结果。
- 新增可爱漫画界面、深红中弹画面、绿色幸运画面和运行内幸运统计。
- 新增 0.72 秒轻量自定义中弹音效；空膛继续使用清脆成功提示音。
- SD 卡新增幸运猫与玩具左轮漫画封面，并更新游戏馆资源清单和校验文件。
- 复用现有 BMI270 任务和音频解码队列，不新增常驻任务。

## 验证结果

- ESP-IDF 5.5 完整构建及合并镜像通过，App 6,817,120 字节，7 MB 分区剩余 522,912 字节。
- 发布附件结构、SD 资源清单及 SHA-256 已校验，App 镜像校验和与 Validation Hash 有效。
- 功能相同的 v1.8.14 候选构建此前已完成实机烧录、联网、天气、时间同步、BMI270、多轮游戏和双结果音效验证；发布 v1.8.15 时电脑未检测到串口，因此未重复烧录，其他设备 OTA 后需确认一次启动版本与联网状态。

## 升级说明

- 普通 OTA / App-only：`qdtech-s3-touch-lcd-3.5-v1.8.15-app.bin`，偏移 `0x100000`。
- 完整恢复：`qdtech-s3-touch-lcd-3.5-v1.8.15-full.bin`，偏移 `0x0`。
- 为显示新封面，请同时把 `qdtech-s3-touch-lcd-3.5-v1.8.15-sdcard.zip` 解压到 SD 卡根目录。

完整技术交接、验证边界、回滚和 SHA-256 见 `docs/V1815_RELEASE_CORRECTION_HANDOFF.md`。
