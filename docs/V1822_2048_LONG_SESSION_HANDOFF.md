# v1.8.22 2048 长局性能修复交接

## 范围

- 基线：GitHub Latest `v1.8.21`。
- 发布版本：`v1.8.22`。
- 仅修改 QDTech 3.5 英寸板的 2048 缓存渲染和快速输入调度。
- 不改变 Wi-Fi、OTA 分区、NVS 布局、SD 卡、音频、语音、天气、摇一摇、数字华容道或 MD 模拟器。

## 根因与修复

用户实测 v1.8.21 在连续操作约 100 步后明显变慢。棋盘逻辑使用固定 16 格数组，10,000 次主机压力循环稳定；风险来自长期重复的 LVGL 工作量：

1. 旧的增量渲染把方块分批完成，再单独完成信息区，一步最多产生五次整张 480×266 Canvas 的失效/提交。屏幕刷新落后于触摸时，待处理工作会随长局累积。
2. 旧的输入背压在每个快速点击波次中创建并删除 25 ms LVGL 定时器，长期运行会增加内部堆碎片风险。

v1.8.22 将同一步的变化方块、得分、最高纪录和状态文本放入同一个 Canvas layer，并且只调用一次 `lv_canvas_finish_layer()`。输入仍只有一个“最后方向”槽，但定时器在页面生命周期内复用：空闲时暂停，有新输入时恢复，离开页面或重开游戏时释放。

## 稳定性边界

- 保留 130 ms 从渲染完成时开始计算的冷却窗口。
- 保留快速输入“只取最新方向”，不会建立 RTOS 队列或累计过期操作。
- 保留方向键布局和重新开始按钮之间 40 px 空白区。
- 保留 `puzzle2048/high_score` 独立 NVS 字段；本次刷写不擦除 NVS。
- Canvas/PSRAM 分配失败时仍回退到 v1.8.21 原绘制路径。
