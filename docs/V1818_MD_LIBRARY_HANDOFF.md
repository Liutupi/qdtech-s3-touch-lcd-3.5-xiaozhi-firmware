# v1.8.18 世嘉主系统游戏目录与启动入口交接

日期：2026-08-07

## 完成内容

本阶段在 `CONFIG_QDTECH_EXPERIMENT_MD_DUAL_MODE` 开启时，为主系统“更多”页增加“MD 游戏”入口和独立全屏目录。实验开关默认关闭，关闭态的固件大小、内部 RAM 和原界面与 v1.8.18 基线完全一致。

目录页优先读取 `/sdcard/roms/md/catalog.tsv`，用于提供中文游戏名和分类；如果该文件缺失或无有效记录，则扫描 ROM 根目录和一层子目录。读取器同时兼容生成工具导出的多列表头格式和三列简洁格式，不会无条件丢弃第一条游戏记录。支持 `.md`、`.gen`、`.bin`、`.smd`、`.zip`，最多 128 项。页面每次显示五项，支持翻页、选择、新游戏/继续游戏和 1–4 存档槽。

“启动”按钮只触发可注入回调。本阶段刻意没有连接 `MdBootService::PrepareAndSelect()`，不会调用 `esp_ota_set_boot_partition()`，不会执行 `esp_restart()`，因此不会因误触而离开主系统。

## SD 卡目录格式

推荐目录：

```text
/sdcard/roms/md/
  catalog.tsv
  roms/
    game-a.bin
    game-b.md
```

`catalog.tsv` 每行三个字段，以制表符分隔：

```text
roms/game-a.bin\t中文游戏名\t动作
roms/game-b.md\t中文游戏名\t角色扮演
```

空行和以 `#` 开头的行会被忽略。ROM 必须位于 `/sdcard/roms/md/` 下，且扩展名属于支持列表。
