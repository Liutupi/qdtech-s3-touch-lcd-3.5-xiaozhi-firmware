# v1.8.12 空当接龙重构交接

## 范围

- 基线为 v1.8.11，仅重构益智游戏馆中的空当接龙。
- Wi-Fi、天气、语音、电台、掌卦、日历、星座、称骨、媒体、其他游戏、分区表及 SD 卡资源格式均未修改。
- 现有 v1.8.11 SD 卡资源可以继续使用，不需要重新复制图片。

## 标准规则

- 使用 8 列牌列、4 个空当和 4 个按花色收牌区。
- 牌列按红黑交替、点数递减构建；空列允许放任意单牌或合法连续牌组。
- 空当只能保存一张牌，空当中的牌可继续移至牌列或收牌区。
- 收牌区按同花色 A 到 K 递增，也允许将顶牌退回牌列，方便修正误操作。
- 连续牌组使用标准超级移动容量：`(空空当数 + 1) × 2^空列数`；目标为空列时不把目标列计入可用空列。
- 所选牌以下必须已经组成红黑交替的连续递减牌组，否则拒绝选择并显示原因。
- 四个收牌区共 52 张时判定胜利。

## 牌局与交互

- 使用经典 Microsoft 编号发牌算法，范围为 1–32000。
- 发牌算法已用经典 #1 布局逐列核对；排除该范围内公认无解的 #11982。
- 支持从牌列、空当和收牌区选择来源；点目标牌列、空当或对应花色收牌区完成移动。
- 非法移动会区分提示：颜色/点数不符、收牌顺序不符、空当占用或临时空间不足。
- 支持连续 24 步撤销、随机新牌局、牌局编号、步数、空空当数量和通关提示。
- 长牌列按列内牌数动态压缩间距，触摸命中计算与绘制间距使用同一规则。
- 牌面及收牌区使用程序绘制的红桃、方块、梅花、黑桃图形，不依赖字体字库；收牌区按该顺序排列，触控映射与显示一致。
- 空当编号及牌局统计统一改用完整中文字库，修复左上角和右下角出现方框乱码的问题。

## 稳定性

- 完整牌局和 24 步撤销历史只在首次进入空当接龙时分配到 PSRAM；不回退占用内部 SRAM。
- 退出并释放益智游戏馆页面时同步释放牌局 PSRAM。
- 完整功能配置必须使用 `build-v188-on/sdkconfig`，其中游戏馆、星座、称骨和电台目录均开启。
