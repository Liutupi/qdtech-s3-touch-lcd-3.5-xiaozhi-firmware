# v1.8.14 幸运左轮候选版交接（已由 v1.8.15 取代）

> v1.8.14 曾短暂发布为候选构建。用户确认自定义中弹音效后，正式公开版本号修正为 v1.8.15；请勿再向设备分发 v1.8.14。

## 范围与基线

- 基线为已发布并验证的 `v1.8.13`，本次只扩展益智游戏馆，未修改 Wi-Fi、天气、语音、电台、掌卦、日历、星座、称骨、媒体、NVS、分区表或其他游戏规则。
- 该候选构建使用 `1.8.14`；相同已验收功能的正式公开版本为 `1.8.15`，供 OTA 正确识别。
- 新游戏名为“幸运左轮”，属于离线漫画运气游戏；画面和音效均采用玩具化、无血腥表现。

## 游戏规则与交互

- 玩家可选择 1–5 颗玩具弹，六孔转轮中签概率分别为 1/6、2/6、3/6、4/6、5/6。
- 装弹位置和最终停下的膛位均使用 `esp_random()`；装弹循环保证没有重复膛位。
- 装弹后启用现有 BMI270 高频路径，摇动设备进入转轮动画，停稳后关闭高频采样，再由玩家点击扳机揭晓。
- 中弹显示深红漫画爆发画面；空膛显示绿色幸运画面。结果页记录本次运行中的幸运次数和总局数。
- 复用了体感迷宫的单一 BMI270 任务、I2C 互斥和 40 ms 采样周期，没有新增常驻任务、队列、信号量或传感器访问者。

## UI、SD 卡与音效

- 游戏馆从 7 项扩展为 8 项，新增中文入口、可爱漫画封面说明和“摇动”标签。
- SD 封面为 `/games/puzzle_arcade/covers/lucky_revolver.jpg`，180×120 JPEG、11,435 字节；设计为粉彩玩具左轮、六孔转轮和幸运猫。
- `manifest.json`、`README.txt` 和 `SHA256SUMS.txt` 已升级到 v1.8.14 并包含新封面。
- 空膛继续使用系统 `P3_SUCCESS`；中弹使用新生成的 `P3_LUCKY_REVOLVER_HIT`，时长 0.72 秒、12 帧、3,021 字节，包含低频冲击、金属转轮回响和三段衰减尾音。
- 新音效仍通过 `PlayNotificationSound()` 的正常 Opus 解码队列播放；电台或音乐占用外部音频时自动抑制，不抢占播放通道。
- `scripts/p3_tools/generate_lucky_revolver_hit.py` 与 `convert_wav_to_p3_minimal.py` 保留了可复现的音效生成和轻量 P3 编码流程；编码后逐帧反解校验通过。

## 构建与实机验证

- ESP-IDF 5.5 完整功能配置 `build-v188-on/sdkconfig` 编译和 `merge-bin` 均通过，CMake 报告版本 `1.8.14`。
- App：`0x680560` / 6,817,120 字节；7 MB App 分区剩余 `0x7faa0` / 522,912 字节（约 7%）。
- 完整恢复镜像：`0x780560` / 7,865,696 字节。
- COM3 App-only 写入 `0x100000` 完成，esptool 写后哈希校验通过；NVS、配网信息和 SD 数据均保留。
- 启动日志确认版本 1.8.14、8 MB PSRAM、SD 卡、电台、Wi-Fi、MQTT、天气 HTTP 200、SNTP 和 BMI270 正常。
- 实机连续完成多轮装弹、摇动、自动停稳和扳机操作；日志确认封面从 SD 加载、40 ms 高频采样按游戏状态启停、扬声器通道正常启用，内部 SRAM 稳定在约 11.3 KB，未出现 panic、看门狗或重启。
- 进入游戏馆时曾出现一次瞬时 I2C 软件超时，随后立即恢复；之后多轮触控与 BMI270 采样均正常，未形成持续故障。
- 自定义中弹音效最终实机版本已烧录，用户确认效果可以。

## 发布与回滚

- OTA / App-only 使用 `qdtech-s3-touch-lcd-3.5-v1.8.14-app.bin`，偏移 `0x100000`。
- 完整恢复使用 `qdtech-s3-touch-lcd-3.5-v1.8.14-full.bin`，偏移 `0x0`；恢复刷写可能清除本地配网状态。
- v1.8.14 已停止分发；其他板子应通过 OTA 升级到 v1.8.15，并使用 v1.8.15 SD 卡包。
- 回滚时 App-only 写入已发布的 v1.8.13 App；SD 上新增封面可保留，旧固件会忽略它。
