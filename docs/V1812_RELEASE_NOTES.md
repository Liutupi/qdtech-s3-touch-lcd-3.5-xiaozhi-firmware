# QDTech v1.8.12 发布记录

发布日期：2026-07-31

## 范围

- 基线为 v1.8.11；保留已验证的 Wi-Fi、天气、语音、电台、掌卦、日历、星座、称骨、SD 卡、NVS 和分区逻辑。
- 本次只完成空当接龙规则重构、花色可视化和界面乱码修复。

## 发布内容

- 空当接龙采用标准 8 列牌区、4 个空当、4 个收牌区规则，支持红黑递减、任意牌组进入空列、超级移动、24 步撤销、收牌胜利和经典 Microsoft 编号牌局。
- 牌面和收牌槽绘制红桃、方块、梅花、黑桃图形，不再使用不直观的 H/C/D/S 字母缩写。
- 修复空当编号和底部牌局统计使用英文字体造成的方框乱码。
- 牌局状态仅在进入空当接龙时于 PSRAM 分配 10,864 字节，避免影响天气等内部 SRAM 敏感功能。
