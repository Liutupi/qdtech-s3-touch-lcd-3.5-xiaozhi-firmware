# QDTech v1.8.9 发布版本修正交接

发布日期：2026-07-30

## 修正内容

- v1.8.8 已承载益智游戏馆第一阶段；随后完成的游戏界面精修、体感迷宫实装、阈值调整与双轴方向反转属于后续修订，OTA 版本必须递增为 v1.8.9。
- 本版本功能内容与 v1.8.8 发布分支一致，仅将 OTA 可见版本和发布产物升级为 v1.8.9，确保设备能够发现新固件。

## 验证要求

- 使用游戏馆开启配置重新构建并生成 App-only、完整恢复及 SD 资源发布包。
- COM3 刷写后确认启动日志显示 `App version: 1.8.9`。
- 常规 OTA 使用 `*-app.bin`；完整镜像仅用于恢复性刷写。
