# v1.8.15 幸运左轮正式版交接

## 版本纠正

- `v1.8.14` 曾短暂作为候选构建发布；用户确认自定义中弹音效后，正式公开版本应为 `v1.8.15`。
- 本次只修正固件版本、SD 卡资源版本、发布说明和发布资产名称；游戏逻辑、漫画资源、自定义音效及此前已验证功能均保持不变。
- GitHub Latest、OTA/App-only 镜像、完整恢复镜像和 SD 卡包统一使用 `v1.8.15`；v1.8.14 保留历史记录并明确标记为已被取代。

## 功能范围

- 益智游戏馆包含数独、密码锁、萌宠推箱、消消乐、体感迷宫、2048、空当接龙和幸运左轮。
- 幸运左轮可选择 1–5 颗玩具弹，摇动开发板旋转转轮，停稳后点击扳机揭晓结果。
- 继续复用现有 BMI270 高频采样任务和音频解码队列，没有新增常驻任务、I2C 访问者或后台服务。
- 中弹使用 0.72 秒轻量自定义音效，空膛使用系统成功提示音；画面保持可爱漫画、无血腥表现。

## SD 卡资源

- SD 封面：`/games/puzzle_arcade/covers/lucky_revolver.jpg`，180×120 JPEG。
- `manifest.json`、`README.txt` 和 `SHA256SUMS.txt` 已统一到 v1.8.15。
- OTA 只更新程序和内置音效；显示新封面还需将 v1.8.15 SD 卡包解压到卡根目录。

## 构建与实机验证

- ESP-IDF 5.5 完整功能配置编译和 `merge-bin` 均通过，CMake 报告版本 `1.8.15`。
- App：`0x680560` / 6,817,120 字节；7 MB App 分区剩余 `0x7faa0` / 522,912 字节（约 7%）。
- 完整恢复镜像：`0x780560` / 7,865,696 字节。
- 发布包结构已检查：分离烧录包 6 个文件，SD 卡包 32 个文件；SD 资源清单校验值已更新。
- 本机发布时未检测到串口，因此没有重复烧录 v1.8.15；功能相同的 v1.8.14 候选构建此前已完成 COM3 写后哈希、启动联网、天气、时间同步、BMI270、多轮游戏和双结果音效验证，并由用户确认音效可用。
- v1.8.15 App 镜像的 esptool 镜像校验和及 Validation Hash 均有效；本次变更仅涉及版本描述和 SD 元数据。其他设备接收 OTA 后仍需观察一次启动版本与联网状态。

## 发布与回滚

- OTA / App-only 使用 `qdtech-s3-touch-lcd-3.5-v1.8.15-app.bin`，偏移 `0x100000`。
- 完整恢复使用 `qdtech-s3-touch-lcd-3.5-v1.8.15-full.bin`，偏移 `0x0`；该方式可能清除本地配网状态。
- 回滚时可 App-only 写入已发布的 v1.8.13 App；不建议回滚到已被取代的 v1.8.14。
