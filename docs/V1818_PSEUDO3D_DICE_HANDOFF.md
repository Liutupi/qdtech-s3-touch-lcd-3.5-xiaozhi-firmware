# QDTech v1.8.18 立体骰子精修与摇一摇全屏化交接

## 发布边界

- 基线为已经发布并验证的 v1.8.17。
- 只调整“摇一摇实验室”的全屏呈现和骰子体验，不合入此前暂缓的 Wi-Fi 实验修复。
- 网络、OTA、音频、天气、电台、日历、掌卦、游戏馆、摇摇电影与摇摇书籍的数据及业务路径不变。
- 两项功能均由默认关闭的实验开关隔离：`CONFIG_QDTECH_EXPERIMENT_PSEUDO3D_DICE` 与 `CONFIG_QDTECH_EXPERIMENT_SHAKE_LAB_FULLSCREEN`。

## 本次实现

- 所有摇一摇实验室子页面移除上方无关信息，改为完整 480×320 内容区。
- 骰子页从 SD 卡直接读取预渲染舞台和抗锯齿 ARGB8888 立体骰子帧；ESP32 只切换帧，不在运行时计算复杂几何和光照。
- 骰子资源只在进入骰子页时载入 PSRAM，退出即释放；总占用 970,752 字节。
- SD 卡缺失、文件尺寸错误或载入失败时自动回退原平面骰子，不阻塞页面。
- 骰子页使用独立的快速摇动参数：2 个峰值、1 次方向反转、90 ms 动作窗；不改变掌卦、木鱼、电影、书籍和轮盘的传感器参数。
- 停摇后约 420 ms 自动揭晓；界面另有第 7 帧兜底停止逻辑，并忽略重复揭晓，避免持续滚动、卡在半路或结算两次。

## 验证结果

- 功能关闭构建与 v1.8.17 基线完全一致：6,838,256 字节（`0x6857F0`）。
- 功能开启的 v1.8.17 测试构建为 6,842,784 字节（`0x6869A0`），仅增加 4,528 字节，OTA 分区仍余 497,248 字节。
- 静态守卫测试通过：资源尺寸、路径、开关隔离、快速判定、自动停止和旧骰子回退均已覆盖。
- 实机连续三轮记录的停摇至揭晓时间分别为 420 ms、452 ms、425 ms；每轮只结算一次，冷却正常结束。
- 实机空闲 SRAM 约 11,295 字节，最低约 9,719 字节；反复测试未出现崩溃、看门狗复位或 low-memory。
- 启动已确认 ESP32-S3、8 MB PSRAM、SDMMC 4-bit、Wi-Fi、MQTT、OTA、天气 HTTP 200 和时间同步正常。
- 用户已确认最终画面与摇动速度可接受。最终发布构建仅更新版本元数据到 v1.8.18；精确发布校验边界见下节。

## 发布与回退

- GitHub Release 应同时提供 App OTA 镜像、完整恢复镜像、固件 ZIP、完整 SD 卡 ZIP 和 SHA256 清单。
- 完整 SD 卡包必须以 v1.8.17 发布包为底，覆盖本仓库当前 `sdcard`，不得遗漏电影和书籍资料。
- 回退只需把 v1.8.17 App 镜像写入当前 OTA 槽；不要擦除 NVS，也不需要删除 SD 卡新增资源。
