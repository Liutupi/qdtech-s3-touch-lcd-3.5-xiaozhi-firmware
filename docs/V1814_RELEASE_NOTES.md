# QDTech v1.8.14 候选版记录（已由 v1.8.15 取代）

> ⚠️ 此版本曾短暂发布，现已由 v1.8.15 正式版取代。请下载并分发 v1.8.15，不要继续使用 v1.8.14。

发布日期：2026-08-02

源码发布提交：`81f9b267`（`release: v1.8.14 lucky revolver`）。

## 主要变化

- 益智游戏馆新增“幸运左轮”：可选择 1–5 颗玩具弹，摇动开发板旋转六孔转轮，停稳后点击扳机揭晓结果。
- 新增可爱漫画界面、深红中弹画面、绿色幸运画面和运行内幸运统计。
- 新增 0.72 秒轻量自定义中弹音效；空膛继续使用清脆成功提示音。
- SD 卡新增幸运猫与玩具左轮漫画封面，并更新游戏馆资源清单和校验文件。
- 复用现有 BMI270 任务和音频解码队列，不新增常驻任务，不改变已验证的网络、天气、语音、电台、日历和其他游戏功能。

## 验证结果

- ESP-IDF 5.5 完整构建及合并镜像通过，App 6,817,120 字节，7 MB 分区剩余 522,912 字节。
- COM3 App-only 烧录及写后哈希校验通过。
- 实机确认 SD 封面加载、多轮六轴摇动、自动停稳、触控扳机和双结果音效；Wi-Fi、MQTT、天气、时间同步和内存保持稳定。

## 升级说明

- 普通 OTA / App-only：`qdtech-s3-touch-lcd-3.5-v1.8.14-app.bin`，偏移 `0x100000`。
- 完整恢复：`qdtech-s3-touch-lcd-3.5-v1.8.14-full.bin`，偏移 `0x0`。
- 为显示新封面，请同时把 `qdtech-s3-touch-lcd-3.5-v1.8.14-sdcard.zip` 解压到 SD 卡根目录。
