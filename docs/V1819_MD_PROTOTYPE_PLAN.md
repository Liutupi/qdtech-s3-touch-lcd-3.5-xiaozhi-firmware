# QDTech v1.8.19 MD/Gwenesis 实验原型计划

## 稳定性边界

- 基线固定为正式发布提交 `73947a79fccd0208fad7a35376929913f6e7edbd`（v1.8.18）。
- 实验在独立分支和独立工作区进行，不读取当前开发目录里尚未发布的 Wi-Fi 与依赖改动。
- 第一阶段不修改正式固件、不修改分区表、不擦除 NVS，也不发布 ROM。
- 任何 App 分区溢出、内部 SRAM 安全余量下降、天气/语音/网络回归或退出后资源不恢复，都视为不能合入。

## 本地全集审计

- 全集共 3,641 个文件、约 2.37 GiB；其中 `roms` 目录有 3,462 个 ZIP。
- 识别到 3,389 个 MD ROM：1,863 个 `.smd`、1,239 个 `.bin`、227 个 `.md`、45 个 `.gen`，另有少量 `.mdx`。
- 3,107 个 ROM 不超过 2 MiB，272 个在 2–4 MiB，10 个超过 4 MiB；中位大小 1 MiB，最大约 9.66 MiB。
- 1,863 个 `.smd` 条目中只有 25 个是经典 512 字节头交织格式；1,810 个实际是线性 ROM 但扩展名误写为 `.smd`，另有 28 个需单独鉴别。测试包按内容签名重新命名，不能按后缀盲目载入。
- 1,906 个压缩包除 ROM 外还带说明文件，不能直接作为单 ROM ZIP 使用；测试包只提取 ROM 条目。
- 29 个 32X 游戏不进入本项目；32X 不属于普通 MD/Gwenesis 支持范围。

## 代表性测试集

- `tools/prepare_md_test_pack.ps1` 从用户本地目录确定性提取 20 个代表性 ROM 到忽略目录 `tmp/md-test-pack`。
- 核心组覆盖动作、清版、射击、竞速、策略和 RPG，以及 BIN、SMD、MD 三种格式。
- 3 MiB 组只在核心组稳定后测试；5 MiB《超级街头霸王2》只作为内存和六键输入极限测试。
- ROM、哈希和生成后的测试包不得提交或上传 GitHub。

## 许可证边界

- 当前主项目为 MIT。
- Retro-Go 的 Gwenesis 快照使用 AGPLv3；把它静态链接进主 App 会改变组合固件的发布义务。
- 在用户明确决定许可证方案前，只允许本地独立实验，不得把 Gwenesis 源码或组合固件推送到主仓库或制作正式 Release。

## 技术门槛

- 当前 v1.8.18 App 为 6,842,784 字节，7 MiB App 分区仅余 497,248 字节。
- 板子为 ESP32-S3 240 MHz、8 MiB Octal PSRAM 80 MHz；MD 原生 320×224/240，适合 480×320 屏幕。
- 首轮仅承诺三键 MD 游戏；六键格斗的 X/Y/Z/Mode 需要单独触屏布局。
- 游戏模式必须独占显示和音频，按顺序暂停媒体/语音与大图资源，退出后逐项恢复并验证天气、网络、OTA、FC 和摇一摇功能。

## 阶段验收

1. 核心组 ROM 能识别并启动，连续运行 10 分钟，无崩溃、看门狗或 low-memory。
2. 画面比例、NTSC/PAL、A/B/C/Start、音频节奏和帧跳可接受。
3. 退出游戏后 PSRAM/内部 SRAM 回到进入前安全区间，所有稳定功能恢复。
4. 再测试 3 MiB ROM；最后单独测试 5 MiB 与六键，不让极限游戏拖累核心兼容集。
