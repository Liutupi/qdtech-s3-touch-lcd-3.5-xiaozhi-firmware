# v1.8.20 暖色主题视觉升级交接

日期：2026-08-10

## 发布结论

v1.8.20 在已经发布并验证的 v1.8.19 世嘉 MD 双模式基线上，只优化暖色主题视觉和对应图像资源。主系统功能路径、7 MiB 双 OTA 槽、尾部 `mdemu` 分区、Wi-Fi、OTA、音频、游戏和 SD 卡协议均保持不变。

本次发布没有把视觉优化扩大为全局 UI 重构。暖色主题使用独立条件分支，经典主题和猫咪主题继续使用原配色、布局与资源。

## 视觉实现

- `qd_tupi_bot_*.gif/.c`：9 种暖色小智状态动画，显示槽保持 300×238，不改变既有状态机。
- `qd_tupi_avatar.c`：40×40 RGB565 主页/应用页品牌头像。
- `qd_tupi_daily.c`：64×52 RGB565 “今日一句”小智插画。
- 主页仍调用原 `attach_brand_earth()`，Wi-Fi 旁旋转地球没有删除或替换。
- 暖色主页、天气、时间、菜单、今日一句和应用卡片使用暖米白、酒红、琥珀金与灰绿调色板。
- 应用卡片的按下/聚焦状态改用酒红边框和浅暖底色，避免白色高亮覆盖浅色文字。

资源可通过以下脚本重新生成：

```text
tools/generate_warm_xiaozhi_assets.py
tools/generate_warm_theme_ui_assets.py
```

高分辨率源图保存在 `artifacts/theme-redesign/` 对应 source 目录；固件只链接压缩 GIF 和小尺寸 RGB565 C 数组。

## 稳定性边界

- 没有修改 Wi-Fi 配网、已保存网络、HTTP 手机配置页和 MQTT 流程。
- 没有修改 OTA 下载、分区选择、版本比较或回滚逻辑。
- 没有修改 MD 启动、存档、退出和返回主系统逻辑；`mdemu` 镜像沿用 v1.8.19 验证版本。
- 没有修改小智状态机、音频焦点、电台、天气请求、日历、摇一摇实验室或益智游戏逻辑。
- 新资源只增加主 App Flash 占用，不新增常驻任务、网络连接或 SD 卡读写。

## OTA 验收建议

1. 用一块 v1.8.19 板执行“检查更新”，确认发现 v1.8.20。
2. 确认下载附件精确为 `qdtech-s3-touch-lcd-3.5-v1.8.20-app.bin`。
3. 重启后确认版本 1.8.20，检查暖色主页头像、旋转地球、今日一句插画、应用卡片选中状态和小智 9 种状态。
4. 回归 Wi-Fi、天气、时间、小智语音、电台、日历、摇一摇实验室、游戏馆和 MD 启动/退出。
5. 已安装 MD 双模式的板确认 MD 入口仍存在；旧分区板确认不可用入口仍被安全隐藏。

## 回滚

- 主系统回滚：App-only 写回 v1.8.19，不擦除 NVS 和 SD 卡。
- 双模式板只回滚主 App 时保留 `mdemu` 和 SD 卡存档。
- 不要把 full 镜像或 `mdemu.bin` 当作普通 OTA App。
