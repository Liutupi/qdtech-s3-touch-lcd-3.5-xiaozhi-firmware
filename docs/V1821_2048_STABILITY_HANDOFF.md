# v1.8.21 益智游戏馆 2048 稳定性修复交接

日期：2026-08-10

## 发布结论

v1.8.21 基于已发布并验证的 v1.8.20，只优化益智游戏馆中 2048 的移动与绘制路径。Wi-Fi、天气、时间、语音、音频、电台、日历、摇一摇功能、SD 卡和 MD 双模式均未改变。

## 问题原因

2048 的 4×4 棋盘使用 LVGL 自定义绘制。旧实现每次触摸方向键都会重绘整个棋盘；即使该方向无法移动，也会重新创建 16 个方块阴影和最多 16 个装饰高光对应的绘制任务。联网、MQTT、天气和界面同时运行时，内部 SRAM 余量较小，长时间连续操作会放大瞬时内存压力，表现为卡顿或死机。

## 本次修复

- 无法移动的方向直接返回，不再刷新状态文字和整块棋盘。
- 去除每格独立阴影与填充方块上的额外装饰高光，保留圆角、边框、配色和数字，降低每帧绘制任务数量。
- 棋盘数值与最大方块由 16 位扩展为 32 位，避免长局合并到高数值时溢出。
- 不新增后台任务、定时器、动态缓存或 SD 卡资源，不改变游戏规则和触控区域。

- 对着无法移动的边界方向连续点击，确认无卡顿、无全屏闪烁、无死机。
- 检查数字、方块配色、得分、最大方块、重新开始和退出操作。
