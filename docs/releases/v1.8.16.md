# QDTech v1.8.16 功德木鱼正式版

发布日期：2026-08-04

## 新增

- “摇一摇实验室”新增“功德木鱼”。
- 支持触摸与 BMI270 轻敲识别，每次显示“功德 +1”动画。
- 加入短促、清脆、偏厚重且无多余尾音的木鱼音效，最终音量提升 6 dB。
- 加入 240 × 160 RGB565 SD 背景资源和内置绘制兜底。

## 稳定性边界

- 复用 BMI270 任务和现有通知音频队列，不新增任务。
- 木鱼敲击检测仅在对应页面启用，并设 200 ms 限流。
- 音效仅在设备空闲且无外部音频焦点占用时播放。
- 不改 NVS、分区布局、网络配置、OTA 协议和其他板型默认配置。

## OTA 与回退

- 日常 OTA 使用 `qdtech-s3-touch-lcd-3.5-v1.8.16-app.bin`。
- 全量恢复使用 `qdtech-s3-touch-lcd-3.5-v1.8.16-full.bin`，仅用于有线恢复。
- 需要回退时仅刷 v1.8.15 App；不要擦除 NVS。

完整实现与许可证说明见 `docs/V1816_WOODEN_FISH_HANDOFF.md`。
