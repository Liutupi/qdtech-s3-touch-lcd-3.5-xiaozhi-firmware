# QDTech v1.8.19 世嘉 MD 双模式版

发布日期：2026-08-08

## 本版内容

- 在不改变现有小智主系统运行方式的前提下，增加独立的世嘉 MD / Genesis 模拟器模式。
- “更多”页增加中文 MD 游戏目录，可从 SD 卡直接选游戏、新游戏或继续游戏，并选择 1–4 号存档槽。
- 模拟器使用独立 `mdemu` 分区运行；退出时自动保存完整状态并安全返回进入前的主固件槽。
- 优化触控摇杆和底部按键布局、方向反馈、画面比例、刷新与中文目录显示。
- 修复“益智游戏馆”入口和馆内选中卡片使用白色高亮导致文字看不清的问题。
- 修复 MD 退出后卡死，并为返回主系统后的 Wi-Fi 恢复增加一次性宽限时间；普通开机流程不变。

## OTA 兼容性

v1.8.18 及更早使用 7 MiB 双 OTA 分区的板子，可以直接通过普通 OTA 更新 v1.8.19 主固件。OTA 附件名为：

```text
qdtech-s3-touch-lcd-3.5-v1.8.19-app.bin
```

旧分区表中没有 `mdemu`，所以普通 OTA 不可能凭空增加模拟器分区。v1.8.19 会在启动时验证模拟器分区和镜像：

- 已做过一次“双模式完整刷机”的板子：显示“MD 游戏”入口并可正常进入。
- 只通过 OTA 升级的旧板子：继续获得主系统修复，但自动隐藏不可用的 MD 入口，不会出现选择游戏后白屏。

若要让旧板子获得 MD 模式，需首次通过 USB 使用 v1.8.19 完整双模式镜像；该操作不包含 ROM。完成一次后，后续主系统仍可继续普通 OTA。本版暂不支持单独远程更新模拟器镜像。

## SD 卡与 ROM

- 游戏 ROM 放在 `/roms/md/`，中文目录文件为 `/roms/md/catalog.tsv`。
- 存档放在 `/retro-go/saves/md/`，正常退出时自动写入 SD 卡。
- 发布包不提供、不复制也不上传任何商业 ROM；用户应只使用自己合法持有的游戏镜像。
