# QDTech v1.8.20 暖色主题视觉升级

发布日期：2026-08-10

## 本版内容

- 重新设计“暖色”主题的小智形象，补齐待机、聆听、说话、思考、开心、惊讶、难过、生气和困倦 9 种动画状态。
- 主页左上角改为暖色小智头像，同时保留 Wi-Fi 旁原有的旋转地球动画。
- “今日一句”卡片增加暖色小智插画，并重新分配文字区域，避免插画与正文重叠。
- 统一暖米白、酒红、琥珀金和灰绿配色，增强时间、天气、菜单和应用卡片的层级与对比度。
- 优化应用中心卡片尺寸、间距、圆角和选中状态，避免浅色高亮导致文字看不清。
- 优化暖色主题小智状态页和底部状态栏，但不改变网络、OTA、语音、音频、MD、游戏或导航逻辑。

## OTA 与双模式兼容性

- 普通 OTA 使用 `qdtech-s3-touch-lcd-3.5-v1.8.20-app.bin`，只更新主系统，不擦除 NVS、Wi-Fi 配置或 SD 卡。
- 已安装 MD 双模式的板子 OTA 后继续使用原 `mdemu` 分区和 SD 卡存档。
- 没有 `mdemu` 分区的旧板可正常 OTA，系统仍会隐藏不可用的 MD 入口。
- 只有首次安装 MD 双模式时才需要 USB 完整镜像；本版没有改变 v1.8.19 的分区布局和模拟器镜像。
