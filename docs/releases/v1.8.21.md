# QDTech v1.8.21 2048 稳定性修复

发布日期：2026-08-10

## 本版内容

- 优化益智游戏馆 2048 的绘制路径，显著减少每次移动产生的临时绘制任务，降低长时间游玩时的内部内存压力。
- 无法移动的方向不再触发整块棋盘重绘，改善连续操作时的响应速度和稳定性。
- 将 2048 棋盘数值扩展为 32 位，避免长局高数值方块溢出。
- 保留原有规则、布局、圆角、边框、配色、触控区域和操作方式。
- 本版不改动 Wi-Fi、天气、时间、语音、音频、电台、日历、摇一摇、SD 卡或 MD 双模式逻辑。

## OTA 与双模式兼容性

- 普通 OTA 使用 `qdtech-s3-touch-lcd-3.5-v1.8.21-app.bin`，只更新主系统，不擦除 NVS、Wi-Fi 配置或 SD 卡。
- 已安装 MD 双模式的板子 OTA 后继续使用原 `mdemu` 分区和 SD 卡存档。
- 没有 `mdemu` 分区的旧板可正常 OTA，系统仍会隐藏不可用的 MD 入口。
- 只有首次安装 MD 双模式时才需要 USB 完整镜像；本版没有改变分区布局和模拟器镜像。
