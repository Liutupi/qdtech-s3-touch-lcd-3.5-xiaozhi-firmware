# QDTech v1.8.18 立体骰子与摇一摇全屏版

发布日期：2026-08-05

## 立体骰子升级

- 骰子改用 SD 卡预渲染的全屏舞台、12 帧立体滚动动画和 6 组落定画面，补足透视、明暗、倒角与阴影层次。
- ESP32 运行时只负责帧切换，避免实时绘制复杂几何导致卡顿。
- 骰子页图片按需载入 PSRAM，退出页面立即释放；SD 资源缺失时自动回退原平面骰子。
- 结果严格为 1–6 点，支持一次摇 1、3 或 6 颗骰子。

## 摇动体验修复

- 骰子页独立使用更灵敏的起摇判定，不改变掌卦、功德木鱼、电影、书籍和轮盘等已验证玩法。
- 停摇后约 420 ms 自动揭晓，另有界面自动停止保护，解决要摇很久、滚动停不下来或卡在半路的问题。
- 重复揭晓会被忽略，每次摇动只结算一次。

## 全屏显示

- “摇一摇实验室”所有子页面统一使用完整 `480 × 320` 内容区，移除顶部无关信息。
- 摇摇电影与摇摇书籍继续保留大封面、完整介绍和上下滑动。

## 稳定性边界与验证

- 基于 v1.8.17，只改摇一摇页面和骰子路径；未合入暂缓的 Wi-Fi 实验修复。
- App 为 6,842,784 字节，7 MB App 分区剩余 497,248 字节。
- 静态守卫测试通过；实机三轮停摇至揭晓分别为 420 ms、452 ms 和 425 ms，每轮只结算一次。
- 实机测试期间 Wi-Fi、MQTT、OTA、天气 HTTP 200 与时间同步正常，无崩溃、看门狗复位或 low-memory。
- 最终 v1.8.18 镜像与已通过实机测试的程序逻辑相同，仅更新版本元数据；App SHA-256 为 `ABC542DB707ECC89FA05A1B307B7D78003FE40520EA2A5430EB5F09B1C51A24B`。

## SD 卡

把 `qdtech-s3-touch-lcd-3.5-v1.8.18-sdcard.zip` 解压到 SD 卡根目录。完整包保留电影、书籍、日历、游戏和功德木鱼，并新增：

- `/shake_lab/dice/stage.rgb565`
- `/shake_lab/dice/roll.argb8888`
- `/shake_lab/dice/land.argb8888`

## OTA 与回退

- 日常 OTA 使用 `qdtech-s3-touch-lcd-3.5-v1.8.18-app.bin`。
- 有线完整恢复使用 `qdtech-s3-touch-lcd-3.5-v1.8.18-full.bin` 或 firmware ZIP；正常升级不要擦除 NVS。
- 回退仅需 App-only 刷回 v1.8.17，SD 卡资源可以保留。

完整技术交接见 `docs/V1818_PSEUDO3D_DICE_HANDOFF.md`。
