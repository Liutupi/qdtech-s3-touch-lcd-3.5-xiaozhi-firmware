# QDTech v1.8.17 摇摇电影与摇摇书籍正式版

发布日期：2026-08-05

## 新增

- “摇一摇实验室”新增“摇摇电影”和“摇摇书籍”。
- SD 卡内置电影与书籍各 250 条离线推荐资料和封面，摇动设备、停稳后随机揭晓。
- 电影和书籍共用轻量后台加载机制，不新增传感器或常驻服务任务。

## 显示优化

- 推荐页使用完整 `480 × 320` 画面，去掉顶部通用介绍。
- 左侧以原始 `220 × 300` 封面生成大图预览。
- 右侧完整显示标题、评分、主创/作者、年份与简介；内容较长时可上下滑动。
- 右上角保留“返回”按钮。

## 稳定性边界

- 复用现有 BMI270 采样、摇动状态机和后台任务。
- 索引采用蓄水池抽样，不把 250 条资料整体载入内存。
- JPEG 输入和 RGB565 输出缓冲放在 PSRAM，离开页面或再次推荐时释放。
- 不修改 Wi‑Fi、NVS、分区表、OTA 协议、音频、天气、日历、电台及游戏功能。

## 构建与实体板验证

- App：6,838,256 字节；SHA-256 `78dd6e3ceec5e5079d2efa2d61d6f171a0b5d91b8fb7f47f894860f353ff8e9c`。
- 7 MB App 分区剩余 501,776 字节，约 7%。
- 镜像 Checksum 与 Validation Hash 有效。
- 已 App-only 烧录到实体板 `ota_0` / `0x100000`，写入哈希校验成功，未改 NVS。
- 串口确认启动版本 1.8.17，SD、Wi‑Fi、MQTT、天气和 OTA 检查路径正常，无 panic、看门狗或循环重启。

## SD 卡

把 `qdtech-s3-touch-lcd-3.5-v1.8.17-sdcard.zip` 解压到 SD 卡根目录，至少应存在：

- `/movies/catalog.tsv` 与 `/movies/posters/`
- `/books/catalog.tsv` 与 `/books/covers/`

发布包同时保留日历、游戏和功德木鱼资源。

## OTA 与回退

- 日常 OTA 使用 `qdtech-s3-touch-lcd-3.5-v1.8.17-app.bin`。
- 完整恢复使用 `qdtech-s3-touch-lcd-3.5-v1.8.17-full.bin`，仅用于有线恢复。
- 回退仅刷 v1.8.16 App，不擦除 NVS。

完整技术交接见 `docs/V1817_SHAKE_RECOMMENDATIONS_HANDOFF.md`。
