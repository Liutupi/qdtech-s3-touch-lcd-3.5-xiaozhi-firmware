# QDTech v1.8.22 2048 长局性能修复

发布日期：2026-08-11

## 本版内容

- 修复 2048 连续游玩约百步后越来越慢的问题。
- 每个有效移动只提交一次完整画布，避免多个全屏刷新长期排队。
- 快速点击复用单个暂停式输入定时器，避免长局反复分配和释放 LVGL 对象。
- 保留快速输入背压、方向键与重新开始防误触间距、历史最高纪录和原有游戏规则。
- 其他应用、Wi-Fi、天气、音频、SD 卡和 MD 双模式均未改动。

## OTA

- 普通远程升级使用 `qdtech-s3-touch-lcd-3.5-v1.8.22-app.bin`。
- OTA 只更新主系统，不擦除 Wi-Fi/NVS、SD 卡或已有 MD 模拟器分区。
- 完整镜像仅用于 USB 恢复或首次安装 MD 双模式，写入地址为 `0x0`。
