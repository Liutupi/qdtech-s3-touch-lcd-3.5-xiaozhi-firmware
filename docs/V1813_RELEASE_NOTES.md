# QDTech v1.8.13 发布记录

发布日期：2026-07-31

## 版本定位

- v1.8.12 完成了空当接龙标准玩法重构与实机验证。
- v1.8.13 是在其后完成花色图形、收牌区顺序及中文方框乱码修复后的公开发布版本，因此 OTA 可见版本递增为 `1.8.13`。

## 发布内容

- 完整可玩的标准空当接龙：8 列牌区、4 个空当、4 个收牌区、红黑递减、空列、超级移动、24 步撤销、胜利判定及经典 Microsoft 编号牌局。
- 牌面与收牌区显示红桃、方块、梅花、黑桃图形，取代难以辨认的 H/C/D/S 英文缩写；显示和触控收牌槽严格一致。
- 修复左上角空当编号与右下角牌局统计因使用英文字体而显示为方框的问题。
- 保留已验证的 Wi-Fi、天气、语音、电台、掌卦、日历、星座、称骨、其他游戏、SD 卡格式、NVS 与分区配置。

## 发布验证

- 使用完整功能配置 `build-v188-on/sdkconfig` 构建，日历称骨、星座、电台目录和益智游戏馆均开启。
- App-only 实机写入 COM3 并完成数据哈希校验；NVS、配网信息和 SD 卡内容保留。
- ESP-IDF 5.5 完整构建通过：App `0x67db60` / 6,806,368 字节，7 MB 应用分区剩余 `0x824a0` / 533,664 字节（约 7%）。
- COM3 App-only 写入、数据哈希校验与硬复位均通过；启动日志确认 App version `1.8.13`、8 MB PSRAM、Wi-Fi、MQTT、SNTP 及天气 HTTP 200 正常，未见 panic、断言或内存不足。

## 升级说明

- 普通 OTA / App-only 使用 `qdtech-s3-touch-lcd-3.5-v1.8.13-app.bin`，偏移 `0x100000`。
- 完整恢复使用 `qdtech-s3-touch-lcd-3.5-v1.8.13-full.bin`，偏移 `0x0`；仅用于恢复性刷写。
- SD 卡资源未改动，继续使用 v1.8.11 的 `games/puzzle_arcade` 目录即可。
