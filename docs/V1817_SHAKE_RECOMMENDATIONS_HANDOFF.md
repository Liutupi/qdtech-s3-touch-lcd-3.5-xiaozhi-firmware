# QDTech v1.8.17 摇摇电影与摇摇书籍交接

更新日期：2026-08-05

## 发布范围

- 基线：GitHub tag `v1.8.16`，提交 `79a7b06`。
- 新入口：“摇一摇实验室”底部新增“摇摇电影”和“摇摇书籍”，保留原有功德木鱼及全部已验证功能。
- 数据：电影与书籍各 250 条，索引、简介和封面均放在 SD 卡，不写入固件分区。
- 交互：复用现有 BMI270 采样和摇动状态机；停稳后在现有后台任务中随机选取记录并解码封面，不新增常驻任务。

## SD 卡结构

- 电影索引：`/movies/catalog.tsv`
- 电影封面：`/movies/posters/*.jpg`
- 书籍索引：`/books/catalog.tsv`
- 书籍封面：`/books/covers/*.jpg`
- 两类索引共用 TSV 字段：`id / title / primary / secondary / meta / rating / summary / image`。
- 推荐使用发布附件 `qdtech-s3-touch-lcd-3.5-v1.8.17-sdcard.zip`，解压到 SD 卡根目录；它同时保留日历、游戏和功德木鱼资源。

## 实现与内存边界

- 使用一次遍历的蓄水池抽样，扫描索引时只保留当前候选记录，不把 250 条资料整体载入内存。
- 记录与 JPEG 输入、输出均优先分配在 PSRAM；当前标准封面为 `220 × 300`，RGB565 解码缓冲约 132 KB。
- 解码完成后由页面持有唯一图像缓冲；再次摇动、退出页面或销毁 UI 时释放。
- 不修改 Wi‑Fi、NVS、OTA 协议、分区表、音频焦点、天气、日历、电台或游戏逻辑。

## v1.8.17 全屏详情优化

- 推荐详情页使用完整 `480 × 320` 画面，隐藏通用实验室标题和顶部介绍。
- 左侧封面按原始 `220 × 300` 解码后等比例缩放到大图区域，避免旧版先缩至 `110 × 150` 导致画面过小。
- 右侧标题、评分、主创/作者、年份、元数据和简介使用纵向滚动阅读区，长内容不再截断。
- 右上角保留小型“返回”按钮，标题宽度避开按钮区域。
